# WordStorm

WordStorm est une application mobile de jeu de catégories de mots, développée avec Flutter.

## Principe du jeu

Les joueurs répondent à une série de catégories à partir d’une lettre tirée au début de chaque manche. Une manche se termine lorsque le temps est écoulé ou qu’un joueur déclenche **STOP**. Les réponses sont ensuite vérifiées et les points attribués selon leur validité et leur originalité.

## Fonctionnalités prévues

- Créer ou rejoindre une partie et choisir les paramètres d’une manche.
- Jouer avec une lettre et des catégories communes à tous les participants.
- Saisir et valider les réponses à la fin de la manche.
- Calculer les scores, avec un bonus de 15 points prévu par le cahier des charges.
- Consulter le classement et les résultats.

Les règles détaillées et les fonctionnalités prévues sont décrites dans le cahier des charges ci-joint. Les bots et les spectateurs y sont indiqués comme améliorations envisagées après une version stable du jeu.
