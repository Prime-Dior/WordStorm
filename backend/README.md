# Backend WordStorm

Ce dossier accueillera les services serveur. Ils ne sont pas encore installés dans le dépôt ; l'application actuelle utilise les règles et le stockage local du frontend.

Le plan du projet prévoit Firebase pour les salons multijoueurs. Au démarrage de cette phase, ajouter ici les règles et indexes Firestore, les Cloud Functions, leurs tests et un guide de lancement avec l'émulateur.

Ne jamais versionner de clé privée, de jeton ou de fichier de configuration contenant un secret. Les valeurs nécessaires au développement devront être documentées sous forme d'exemple sans secret.
